# Netcatty Mate v3.3.0

## 手机端面板改为底部抽屉（参考 Termius）

以前在手机上打开 Catty Agent、脚本、SFTP 等面板，会盖住整个终端，只能先关掉面板才能看终端输出。现在改成了手机的用法：

- 面板从底部弹出，终端留在上面，一直能看、能点、能输入。
- 面板顶部有拖动条，有三个高度：
  - 迷你：只露出拖动条和工具图标，终端几乎占满全屏。
  - 半屏（默认）：终端和面板上下各占一半。
  - 全屏：面板占大部分屏幕，顶部仍保留几行终端。
- 上下拖动拖动条切换高度，快速下滑可以收起或关闭；轻点拖动条在半屏和全屏之间切换。
- 在脚本面板点运行后，面板自动缩到迷你高度，直接能看到执行结果。
- 在 AI 输入框打字时，面板会自动展开，避免被软键盘挤得太小。
- 下次打开会保持上次选的高度。返回键和 Esc 仍可关闭面板。
- 电脑和平板（宽度 768px 以上）的布局和停靠位置设置不变。

## 验证

- CI 先用 v3.1.7 的布局复现问题，再验证新版本。
- 新版本在 320、375、390 宽的竖屏和深浅主题下测试了：终端始终在面板上方，宽度不受影响；面板没有遮罩，终端仍可点击；轻点和拖动切换高度；下滑关闭；记住高度；返回键关闭。
- 测试使用模拟会话，尚未在真机和真实 SSH 上验证。

## Netcatty Mate v3.1.1

本版发布已通过回归测试的终端时序和 SFTP 文件安全修复；不表示全部功能均已修复或完成真机验证。

### 本版修复
- 取消终端延迟粘贴时清理该会话的定时任务；已进入队列的回调也检查有效性，避免取消后继续发送。关闭、重连、退出和错误等生命周期边界同样失效待发任务。
- 终端 backlog 回放期间缓存实时输出，按顺序交付；退订后清理并抑制延迟回放，避免旧输出再次进入已解绑终端。
- SFTP 覆盖写入在目标目录暂存，保留并读回校验原文件 uid/gid 和权限位；保存符号链接文件时替换解析后的目标而不是链接。元数据无法保留或原子覆盖不受支持时失败并保留旧文件，不先删旧文件。
- 根据 JSch 0.2.21 的 API 行为处理 literal 路径：对会执行 glob 的操作转义反斜线、星号和问号；mkdir、realpath 保持原始路径，避免特殊字符文件名误匹配相邻文件。

### 验证范围
- 11 项真实 JSch / loopback OpenSSH 集成检查，覆盖特殊字符路径、覆盖元数据、符号链接目标、取消和失败保留原文件等行为。
- 15 组移动桥接运行测试、8 项 UI 安全回归、16 项云端恢复回归、11 项 Java 解析及原生安全静态检查。
- GitHub Actions 执行前端打包、修改范围 TypeScript 检查、Android Java/DEX/APK 编译和签名校验。
- 项目仍有既存桌面基线 TypeScript 错误，不宣称全仓类型检查通过。未进行 Android 真机验证，loopback OpenSSH 集成不等于所有实际服务器或云盘端到端验证。

### 功能边界与已知限制
- 云同步保持从远端恢复到本地：不上传、覆盖或删除远端密码库。SFTP 仍为正常双向文件管理，不受云恢复限制。
- Google Drive / OneDrive 的 Android OAuth 回调尚未实现；应用锁、桌面插件/CLI 和部分备份功能仍无 Android 实现，明确提示不可用，不伪报成功。
- SFTP 跨服务器中转暂不支持；服务器不支持原子重命名覆盖时保留旧文件并报告失败。

### 安装与签名
Android 版本号为 3.1.1（versionCode 311）。构建继续使用 v3.1.0 起保存的发布签名 secret，不生成新密钥。v3.0.1 及更早构建可能使用不同的旧证书；如需卸载重装，应先备份本地数据，卸载会删除应用本地数据。

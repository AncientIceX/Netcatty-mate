## Netcatty Mate v3.1.0

本版集中修复 Android 原生宿主、移动端 IPC 桥接、云端恢复和触屏交互问题。

### 功能边界
- 云同步只从远端恢复到本地；禁止上传、覆盖和删除远端密码库。
- SFTP 为正常双向文件管理，与云同步限制无关：支持上传、下载和远端文件操作。
- Android 不支持的桌面专属功能应明确提示不可用，不再伪报操作成功。

### 安装注意
旧版构建流程每次随机生成签名证书，旧签名私钥没有保存。自本版起改用固定、私密保存的发布证书。因此本版可能无法直接覆盖安装 v3.0.1；请先导出/备份本地数据，确认云端密码库和解密密码可用，再卸载旧版并安装。卸载会删除应用本地数据。后续版本将复用本版证书。

### 本版修复
- 终端按会话流式解码 UTF-8，避免中文和 emoji 跨数据包乱码。
- SSH 使用 BouncyCastle 的 X25519/Ed25519 实现，增加严格主机密钥检查。
- 本地凭据改为 AndroidKeyStore AES-GCM 加密，而非明文加前缀。
- SFTP 增加真实双向原生文件操作、流式上传/下载、传输租约及取消清理；下载失败或取消不覆盖原文件，大文件预览不再静默截断。
- WebDAV 使用原生 HTTP 通道；S3 使用实际 AWS SigV4 签名，处理精确对象路径；GitHub 可使用按尝试隔离的 PAT 登录。
- 云端恢复修复先应用、后确认的顺序，避免二次应用及空库阻断；本地编辑不会触发上传。
- 修复软键盘避让、返回导航、剪贴板及首次启动语言识别。
- 移除不可靠的 localStorage 文件镜像回退，防止旧数据复活和假报保存成功。

### 已知限制
- Google Drive / OneDrive 的 Android OAuth 回调尚未实现，当前明确提示不可用。
- 应用锁、桌面插件/CLI 和部分备份功能尚无 Android 实现，不再伪报启用或执行成功。
- SFTP 跨服务器中转暂不支持；基本本地↔远端传输支持。
- 服务器不支持原子重命名覆盖时，编辑/上传会返回失败并保留旧文件，不以先删旧文件的方式冒险覆盖。

### 验证范围
桥接运行测试 11 组、云同步及 UI 回归测试 24 项、Java 解析和安全静态检查 10 项通过。前端打包、修改范围 TypeScript 检查、Android Java/DEX/APK 编译和签名校验由 GitHub Actions 执行。项目上游其他区域仍有既存类型诊断，本版不宣称全仓类型零错误。尚未进行 Android 真机和实际服务器/云盘端到端测试。

## Netcatty Mate v3.1.0

本版集中修复 Android 原生宿主、移动端 IPC 桥接、云端恢复和触屏交互问题。

### 功能边界
- 云同步只从远端恢复到本地；禁止上传、覆盖和删除远端密码库。
- SFTP 为正常双向文件管理，与云同步限制无关：支持上传、下载和远端文件操作。
- Android 不支持的桌面专属功能应明确提示不可用，不再伪报操作成功。

### 安装注意
旧版构建流程每次随机生成签名证书，旧签名私钥没有保存。自本版起改用固定、私密保存的发布证书。因此本版可能无法直接覆盖安装 v3.0.1；请先导出/备份本地数据，确认云端密码库和解密密码可用，再卸载旧版并安装。卸载会删除应用本地数据。后续版本将复用本版证书。

### 验证范围
以本 Release 关联的 GitHub Actions 结果和仓库中的回归测试为准。构建和签名校验通过不等同于所有 Android 设备、全部服务器与全部云盘已完成真机测试。Google/OneDrive 新建 OAuth 登录若未实现 Android 回调，须明确提示限制，不伪报登录成功。
